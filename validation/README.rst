Validation evidence
===================

Files in this directory are the original 0.1.0 early-stage experiments.
The current decision and extended 0.2.0 validation are in ``followup/``.
Original results are retained to preserve provenance; their timings are not
advertised as measurements of 0.2.0. The scripts use the installed version
when rerun. Consult the follow-up guide before reproducing comparisons.
